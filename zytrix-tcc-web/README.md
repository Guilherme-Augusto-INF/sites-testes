# Zytrix TCC — Web

Conversão do projeto **Zytrix-Figma** para HTML, CSS e JavaScript puro.

## Fonte de verdade
- Visual: screenshots em `Zytrix-Figma/docs`.
- Comportamento: Code Layers em `Zytrix-Figma/Zytrix-TCC-code-layers`.
- Backend: Firebase `zytrix-ca4f2`.

## Recursos migrados
- Home e destaques em tempo real.
- Ao Vivo com busca e filtros.
- Categorias + 32 subcategorias.
- Login, cadastro, Google e recuperação de senha.
- Perfil, edição, cooldown de username e verificação de e-mail.
- Criação de conta de streamer e vínculo Twitch.
- Configuração e status da live.
- Player de live e chat simulado do Figma.
- Zy Coins, carteira, apoio e transações.
- Loja e pagamento demonstrativo.
- Logout.
